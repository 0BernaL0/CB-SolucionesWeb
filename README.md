# 🌐 CB - Soluciones Web (Sitio Oficial)
Este es el repositorio oficial de mi sitio web profesional, donde ofrezco servicios de desarrollo y mantenimiento web especializado para negocios y profesionales.

**🔗 URL del sitio:** [https://0bernal0.github.io/CB-SolucionesWeb/](https://0bernal0.github.io/CB-SolucionesWeb/)

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 & CSS3** - Estructura y estilos modernos.
* **Bootstrap 5** - Framework para diseño responsive y componentes de UI.
* **JavaScript** - Funcionalidad interactiva.
* **WebP** - Imágenes de nueva generación para carga rápida.

---

## 📂 Estructura del Proyecto

* `/index.html` - Página principal con secciones de inicio, sobre mí, portfolio de referencia y contacto.
* `/pricing.html` - Planes de mantenimiento y servicios post-venta.
* `/portfolio-general.html` - Galería completa de demos disponibles.
* `/css` & `/js` - Archivos de estilo y lógica.
* `/images` - Recursos visuales optimizados.
